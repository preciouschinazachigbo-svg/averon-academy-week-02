# My Personal Developer Portfolio

## About the Project

This is my personal developer portfolio, created as part of Week 2 of the Averon Academy developer training programme.

The website introduces me, shares my interests and developer goals, highlights the technologies I am learning, and provides a way to connect with me.

## Technologies Used

* HTML5
* CSS3
* Git
* GitHub

## Website Sections

* Home
* About Me
* Skills
* Goals
* Contact

## Features

* Semantic HTML structure
* Responsive layout for mobile and desktop screens
* Navigation links to different sections
* Styled skill and goal cards

## What I Learned

Through this project, I practised structuring a webpage with HTML, styling it with CSS, organizing project files, and preparing to use Git and GitHub to manage and share my work.
